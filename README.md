# vix-extreme-value-modelling-egarch-evt
Code for the MSc dissertation "Tail Risk for the Volatility Index (VIX): A Hybrid Extreme Value Theory Approach" (University of Bath, 2026). AR(1)-EGARCH(1,1)-t filter with a GPD tail for one-day VaR and ES of VIX returns, with a rolling backtest against GARCH-EVT, static POT and EGARCH-t.
